Hospital Database Management & Patient Risk Analysis

In this project, I designed a relational database schema for a Hospital Management System using PostgreSQL.

I focused on linking patient demographics with clinical visit records to streamline administrative tasks and improve patient care through proactive data monitoring.

The goal was to reorganize patient information, identify patients missing follow-up appointments, and prioritize high-risk cases based on physiological data.

1. Database Schema Creation

First, I established the foundation by creating a table to store core patient demographics.

Click here to see my SQL Code 

CREATE TABLE PATIENTS (
    PATIENT_ID INT PRIMARY KEY,
    FNAME VARCHAR(50) NOT NULL,
    LNAME VARCHAR(50) NOT NULL,
    GENDER VARCHAR(10),
    DATE_OF_BIRTH DATE NOT NULL,
    CONTACT_NO VARCHAR(20) UNIQUE,
    PT_ADDRESS TEXT
);
